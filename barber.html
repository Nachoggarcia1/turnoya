Presentación

TurnoYA es una plataforma web pensada para barberías de General Roca que necesitan organizar sus turnos de forma simple y ordenada. Nació como un proyecto académico dentro de la Tecnicatura en Desarrollo de Software Full Stack, pero fue creciendo hasta convertirse en una idea de negocio real.

La propuesta busca resolver un problema concreto: muchas barberías siguen gestionando sus turnos por WhatsApp o de forma manual, lo que genera pérdida de tiempo y superposición de citas. TurnoYA ordena ese proceso en un solo lugar.

Funcionalidades

El sistema está pensado para que tanto el barbero como el cliente tengan una experiencia clara y directa a la hora de reservar o gestionar un turno.

  • Reserva de turnos online
  • Gestión de suscripciones mensuales
  • Panel para que el barbero organice su agenda
  • Recordatorios de turnos próximos

Tecnologías utilizadas

El desarrollo se apoya en tecnologías web estándar, aprendidas durante la carrera:

  1. HTML
  2. CSS
  3. JavaScript
  4. PHP
  5. Base de datos MySQL
